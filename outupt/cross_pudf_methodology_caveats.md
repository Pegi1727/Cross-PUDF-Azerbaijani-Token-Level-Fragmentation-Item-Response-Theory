# Cross-PUDF Azerbaijani tokenizer study

## Execution and outputs
Computed at runtime with real HuggingFace `AutoTokenizer` instances: `bert-base-uncased` (source) and `bert-base-multilingual-cased` (target). Outputs are saved in `C:\Users\PASARGAD PARDAZ\Desktop`. Sentence IDs are zero-based and stable in the script.

## Data and checks
The script contains exactly 100 manually authored Azerbaijani Latin-script sentences, with 25 each in basic everyday, intermediate narrative, advanced academic/technical, and morphologically complex tiers. It validates total size, exact uniqueness, and tier counts before loading tokenizers.

## Measures and scoring
Unicode word count uses Python's Unicode-aware regular expression. Token counts and token strings are generated by each tokenizer with special tokens excluded. Fertility is target token count divided by word count; target/source ratio is target token count divided by source token count. Zero denominators yield zero. The configured score is `b_tilde = 0.0 + 1.0 * target_fertility + 1.0 * target_surface_nonoverlap_proxy`. Z-score uses population standard deviation. Raw min-max maps the observed range to [-3, 3]; robust scaling clips to observed p5/p95 and maps that interval to [-3, 3]. Constant ranges map to zero. `overall_rank` is ascending across all rows; `level_rank` is ascending within tier (average ranks for ties).

## Important diagnostic caveat
`target_surface_nonoverlap_proxy` is the fraction of target token surface strings whose lowercase form is absent from the source tokenizer's vocabulary strings after lowercase comparison. This is a deliberately simple diagnostic proxy, not true lexical coverage or semantic overlap: model vocabularies have different segmentation, normalization, continuation markers (such as `##`), and token conventions. Interpret it cautiously.

## ZPD sampling
For theta -2, 0, and 2, the script samples five batches of ten without replacement within each theta, using seed 42. It sets 2PL difficulty `b` to the standardized b_tilde and discrimination `a` to target fertility clipped to [0.3, 3.0]. Logistic response probability is `P=1/(1+exp(-a*(theta-b)))`; sampling weight is Fisher information `a^2*P*(1-P)`. Selection probabilities are renormalized over remaining items at each draw. Sampling is an illustrative item-selection procedure, not a validated assessment calibration.

## Summary statistics
The summary CSV reports overall and per-tier means, plus Spearman correlation and p-value for Unicode word count versus target token count (computed separately in each scope).

## Reproducibility and limitations
Tokenizer revisions are whatever HuggingFace serves when this script runs; record package/model revisions separately for strict reproducibility. Network access and installed `numpy`, `pandas`, and `transformers` are required; SciPy is not used. No computed scores are claimed until execution completes.
