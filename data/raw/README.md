# Standalone raw sentence corpus

`cross_pudf_sentences_raw.csv` contains exactly `row_id`, `tier`, and `sentence` for 100 manually authored Azerbaijani sentences. This standalone corpus was reconstructed from the `sentence` column of the derived score table, retaining its row identifiers and tier labels; it is not an independent source file or an independently re-collected corpus. See `../processed/data_dictionary.md` and `../../docs/cross_pudf_methodology_caveats.md`.
